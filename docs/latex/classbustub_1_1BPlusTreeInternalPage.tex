\doxysubsection{Detailed Description}
Store n indexed keys and n+1 child pointers (page\+\_\+id) within internal page. Pointer PAGE\+\_\+\+ID(i) points to a subtree in which all keys K satisfy\+: K(i) \texorpdfstring{$<$}{<}= K \texorpdfstring{$<$}{<} K(i+1). NOTE\+: since the number of keys does not equal to number of child pointers, the first key always remains invalid.
