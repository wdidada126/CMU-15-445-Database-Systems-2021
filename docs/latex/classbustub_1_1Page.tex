\doxysubsection{Detailed Description}
\doxylink{classbustub_1_1Page}{Page} is the basic unit of storage within the database system. \doxylink{classbustub_1_1Page}{Page} provides a wrapper for actual data pages being held in main memory. \doxylink{classbustub_1_1Page}{Page} also contains book-\/keeping information that is used by the buffer pool manager, e.\+g. pin count, dirty flag, page id, etc.
