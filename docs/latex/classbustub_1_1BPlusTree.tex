\doxysubsection{Detailed Description}
Main class providing the API for the Interactive B+ Tree.

Implementation of simple b+ tree data structure where internal pages direct the search and leaf pages contain actual data. (1) We only support unique key (2) support insert \& remove (3) The structure should shrink and grow dynamically (4) Implement index iterator for range scan
