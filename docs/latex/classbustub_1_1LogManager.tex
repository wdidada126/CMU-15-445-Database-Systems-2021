\doxysubsection{Detailed Description}
\doxylink{classbustub_1_1LogManager}{Log\+Manager} maintains a separate thread that is awakened whenever the log buffer is full or whenever a timeout happens. When the thread is awakened, the log buffer\textquotesingle{}s content is written into the disk log file.
