Get\+Global\+Depth\+Mask -\/ returns a mask of global\+\_\+depth 1\textquotesingle{}s and the rest 0\textquotesingle{}s.

In Extendible Hashing we map a key to a directory index using the following hash + mask function.

Directory\+Index = Hash(key) \& GLOBAL\+\_\+\+DEPTH\+\_\+\+MASK

where GLOBAL\+\_\+\+DEPTH\+\_\+\+MASK is a mask with exactly GLOBAL\+\_\+\+DEPTH 1\textquotesingle{}s from LSB upwards. For example, global depth 3 corresponds to 0x00000007 in a 32-\/bit representation.

\begin{DoxyReturn}{Returns}
mask of global\+\_\+depth 1\textquotesingle{}s and the rest 0\textquotesingle{}s (with 1\textquotesingle{}s from LSB upwards) 
\end{DoxyReturn}
