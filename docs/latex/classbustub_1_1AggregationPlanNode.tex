\doxysubsection{Detailed Description}
\doxylink{classbustub_1_1AggregationPlanNode}{Aggregation\+Plan\+Node} represents the various SQL aggregation functions. For example, COUNT(), SUM(), MIN() and MAX().

NOTE\+: To simplify this project, \doxylink{classbustub_1_1AggregationPlanNode}{Aggregation\+Plan\+Node} must always have exactly one child.
